How to use this checklist

Data analytics training programs can differ in tools, pace, projects and learner support. Before comparing a course, use this self-assessment to identify what you already know and which skills need more practice.

For each statement, select the option that best describes your current ability. This is a personal learning worksheet—not a certification exam, admission test or guarantee of job readiness.

Tip: Mark “Can do” only when you can demonstrate the skill independently using a spreadsheet, query, dashboard, notebook or project example.

1. Excel and spreadsheet analysis

Self-checkCan doNeed practiceNot started
Use formulas such as IF, SUMIFS, COUNTIFS and lookup functions to answer questions.
Clean a spreadsheet by handling blanks, duplicates, inconsistent labels and data types.
Create a PivotTable or summary table to compare categories and trends.
Build a chart that answers a clear business question and explain its takeaway.

Evidence to keep: a cleaned workbook with formulas, a pivot summary and a short explanation of the findings.

2. SQL and databases

Self-checkCan doNeed practiceNot started
Filter, sort and aggregate records using SELECT, WHERE, ORDER BY and GROUP BY.
Join tables and explain how the join affects the rows returned.
Use CASE, a subquery or a common table expression to solve a practical question.
Use a window function or check a query for duplicates and missing records.

Evidence to keep: commented SQL queries with the business question and expected output described.

3. Statistics and analytical reasoning

Self-checkCan doNeed practiceNot started
Explain mean, median, percentiles and standard deviation in plain language.
Interpret distributions, outliers and changes over time without overstating conclusions.
Explain the difference between correlation and causation.
Understand basic sampling, uncertainty or hypothesis testing concepts.

4. Power BI and data visualization

Self-checkCan doNeed practiceNot started
Import data and perform basic transformations using Power Query.
Build relationships between tables and understand a basic data model.
Create measures or basic DAX calculations for KPIs.
Design a dashboard with clear hierarchy, useful filters and readable visuals.

For examples, review the Data Analytics Dashboard Design Guide.

5. Python and repeatable analysis

Self-checkCan doNeed practiceNot started
Load and inspect data using Pandas.
Clean missing values, duplicates and inconsistent data types.
Group, summarize and visualize data with Python libraries.
Organize an analysis notebook so another person can follow the steps.

6. Business questions and communication

Self-checkCan doNeed practiceNot started
Translate a broad business problem into measurable questions and KPIs.
Explain the key finding and its limitations to a non-technical audience.
Separate a data-supported insight from an assumption or recommendation.
Document a project with its question, data source, method, findings and next steps.

Frequently asked questions

What skills should I learn before data analytics training?

Basic spreadsheet use and comfort with numbers can help, but many beginner learning paths start with Excel, data fundamentals and introductory statistics. Check the prerequisites of each program.

Is this checklist a certification or entrance test?

No. It is a self-assessment worksheet for personal learning planning, not a formal exam, credential or admission requirement.

Do I need Python for data analytics?

Not every entry-level analytics role requires Python. Excel, SQL and a visualization tool are common foundations; Python can help with repeatable analysis, automation and larger datasets depending on the role.

Is Power BI necessary for a data analyst?

Power BI is one widely used business intelligence tool, but organizations may use other platforms. Learn dashboard design and analytical reasoning in addition to a specific tool.

Does completing training guarantee a data analyst job?

No course or checklist can guarantee employment. Outcomes depend on demonstrated skills, projects, experience, interview performance and the requirements of individual employers.

How often should I repeat this assessment?

Repeat it after completing a learning module or project and update your answers based on work you can demonstrate independently.
